- Never commit, amend, push, or create a pull request without explicit user permission
- Never push to production until the dev server is installed and running locally
- When updating or installing a new Syncode/OpenCode desktop build, always launch scripts/verify-prod-install.ps1 in a visible terminal window at the end so windro can see the install result without asking the agent (the agent lives inside OpenCode). The verification window must stay open until dismissed.
- Syncode is fully standalone — no upstream remote and no connection to anomalyco/opencode. Every piece of work gets its own branch: feature/<name> or fix/<name> branched off dev, merged into dev when done, and dev merges into prod only for a release/deploy. Never commit directly to dev or prod.
- Always use the todo tool properly: keep it current while working, mark items completed only when actually done, append new work to the todo list when new tasks come up mid-work, and never leave the todo list hanging with stale items — clear it when the work is finished.
