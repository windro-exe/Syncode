- Fetches content from a specified URL
- Converts HTML to the requested format (markdown by default)
- Use to retrieve and analyze a specific web page

Parameters:
  - url: required, must start with http:// or https://
  - format: "markdown" (default), "text", or "html"
  - timeout: optional seconds, max 120
  - objective: optional natural-language goal — when set, only sections matching the objective are returned (lexical scoring on markdown headings/paragraphs). Use for long pages where you need a specific answer, not the whole document. Markdown format only.
  - maxChars: optional output cap (default 50000, hard max 100000). Lower values force tighter focus when an objective is set.

When to use objective:
  - Page is long (docs, papers, wiki) and you only need one topic from it
  - You're comparing several sources and want each fetch focused on the same question
  - Skip objective when: short page, you need verbatim content (e.g. a config file, a code sample), or you want to skim freely

When to prefer websearch with deep=true instead:
  - You don't have specific URLs yet and need to discover then fetch in one shot
  - You'd otherwise webfetch 3+ pages from the same search

Notes:
  - HTTP URLs auto-upgrade to HTTPS via the server's redirect; we don't rewrite
  - Read-only — no side effects on local files
  - Cloudflare-blocked pages get one retry with an honest UA
